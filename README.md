# Simple Web Developer Portfolio

A lightweight, single-page portfolio website designed for a web developer, featuring an iconic tribute to Cristiano Ronaldo (CR7). This project was built using foundational HTML layouts, legacy semantic tags, and explicit inline styling to demonstrate a solid understanding of core document structure and styling principles.

🔗 **[Live Demo](https://youssefsallem.github.io/html-portfolio/)**

## 🚀 Features
- **Developer Profile Summary:** A straightforward introduction outlining web development focus.
- **CR7 Tribute Section:** A dedicated visual element highlighting the legendary athlete Cristiano Ronaldo.
- **Traditional Alignment Layouts:** Structured explicitly utilizing native alignment mechanics.
- **Pure HTML Architecture:** Built completely without external stylesheets or script dependencies for instant rendering.

## 🛠️ Technologies Used
- **HTML5** (Structure and Media elements)
- **Inline CSS** (Component-level scoping and custom presentation layout)
- **Legacy Semantic Elements** (Leveraging native browser defaults like the `<center>` tag for deterministic visual layouts)

## 📦 Getting Started

To view this portfolio locally on your machine, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project folder:**
   ```bash
   cd YOUR_REPOSITORY_NAME
   ```

3. **Open the project:**
   Double-click the `index.html` file to launch it instantly in any modern web browser (Chrome, Edge, Safari, Firefox).
